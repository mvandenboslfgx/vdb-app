# Brand assets

Place official VDB Digital logo files in this folder with these exact filenames:

| File | Usage |
|------|--------|
| `logo-mark.png` | Square mark / app icon source (1024×1024 preferred) |
| `logo-mark@2x.png` | 2× mark for dense displays |
| `logo-mark@3x.png` | 3× mark for dense displays |
| `logo-horizontal-light.png` | Horizontal lockup on dark backgrounds |
| `logo-horizontal-dark.png` | Horizontal lockup on light backgrounds |
| `splash-logo.png` | Splash screen centered mark |
| `favicon.png` | Web favicon (48×48 or larger) |

Until these assets are provided, the app uses the temporary `BrandMark` text component from `@/design-system`.
